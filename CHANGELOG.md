# Changelog

All notable changes to `mwguerra/web-terminal-stream` will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Security

- The WebSocket server now validates the `Origin` header of every browser handshake against the (re-added) `stream.allowed_origins` config key (default `[env('APP_URL', 'http://localhost')]`). Disallowed origins are rejected with HTTP 403 — and logged at warning level — before the single-use auth token is consumed. Requests without an `Origin` header (non-browser clients) still pass through to token auth; a literal `'*'` entry (or an empty list) disables the check.

### Added

- **`Schemas\Components\TerminalWorkspace` — tmux-style dynamic tiling.** One terminal that splits into arbitrarily nested panes at runtime: prefix-key shortcuts (default `ctrl+b` + `%`/`"`/`x`/`z`/arrows/hjkl, fully remappable via `keymap()`/config), drag-resizable dividers, keyboard resize, pane zoom (siblings stay live), directional focus navigation, a per-pane close (×) button shown whenever more than one pane exists (the sole remaining pane has none and fills the workspace), and an empty-state respawn. Backed by `Livewire\StreamWorkspace` (pane roster + binary split tree as Locked props; every mutation server-validated: `useStreamTerminal` gate, `maxPanes` ceiling, ratio clamping) and `Data\Layout\LayoutTree` (pure split/collapse/ratio operations, persistence-ready wire shape). New panes clone their split source (tmux semantics) or a `defaultPane()` template evaluated at schema build. Panes render as a flat keyed list of absolutely-positioned siblings with Alpine-bound geometry, so a live pane's canvas and WebSocket never re-render when a sibling splits or closes.
- `Enums\PaneAction` and `Data\Keymap` — the configurable keyboard-shortcut model for the upcoming `TerminalWorkspace` tiling component. `Keymap::tmux()` ships the tmux preset (prefix `ctrl+b`, `%`/`"` splits, `x` close, `z` zoom, arrows/hjkl focus, ctrl+arrows resize); `->prefix()`, `->bind()`, `->unbind()` customize it; `Keymap::fromArray()` hydrates the new `workspace.shortcuts` config section. New `workspace` config block: `shortcuts`, `max_panes`, `min_pane_ratio`, `resize_step`.
- `ConnectionConfig::toTransportArray()` — the full wire-format array (credentials included) handed to the PTY bridge; `toArray()` stays credential-free for logging/display.
- `Schemas\Components\TerminalGrid` — first increment of the tiling layer. Lays out N `WebTerminalStream` panes in a flush CSS grid: `TerminalGrid::make()->panes([...])` with Filament-style responsive `columns()` (default 2), `paneGap(int $px)` (positive gaps render as pane dividers via the container background), `height(string)` with equally shared rows, auto-applied `frameless()` + `squareCorners()` per pane (a pane's explicit setting wins), grid-level `connectionBehavior()` forwarded to panes without their own, a CSS `:focus-within` focused-pane ring, and per-pane wire:key isolation. Manual composition of frameless terminals in your own Grid still works.
- `connectionBehavior()` is now fully implemented instead of merely accepted. `ConnectionBehavior::Manual` renders a themed, centered Connect affordance and opens the WebSocket (and PTY) only on click — never-opened panes cost no server process and write no connection log rows. `Auto` auto-connects and adds a connect/disconnect toggle (header action, or floating overlay control when `frameless()`), with a Reconnect affordance after disconnect. The schema component default remains `Always` (auto-connect, no controls), so existing code is unaffected. Disconnect closes the WebSocket with a clean client close (code 1000).
- Initial extraction of the Stream terminal from [`mwguerra/web-terminal`](https://github.com/mwguerra/web-terminal) (its `feature/frameless` branch) as a standalone, Stream-mode-only package.
- Full interactive PTY over WebSocket (ReactPHP server + ghostty-web WASM terminal emulator), for local shells and SSH (password or key auth).
- Filament integration: `WebTerminalStream::make()` schema component, `WebTerminalStreamPlugin` with a Terminal page and a Terminal Logs resource.
- Connection lifecycle auditing: `StreamTerminal` dispatches `TerminalConnectedEvent` / `TerminalDisconnectedEvent` and records them to the `terminal_stream_logs` table via `TerminalLogger`.
- Artisan commands: `terminal-stream:install`, `terminal-stream:serve`, `terminal-stream:make-page`, `terminal-stream:logs:cleanup`.
- **Docker-backed integration suite** (`composer test:integration`): a throwaway alpine sshd container (`tests/docker/`, committed test-only keys) exercises real SSH password/key/passphrase auth, echo round-trips, remote PTY resize, and termination; a Linux php container covers the Linux-only local-PTY resize path; a full-stack test boots `terminal-stream:serve` and drives it with a real WebSocket client (token auth, Origin rejection, single-use token replay).
- **Playwright e2e suite** (`npm run test:e2e`): `scripts/e2e/setup.sh` scaffolds a dedicated Laravel 13 + Filament 5 app into the gitignored `tests/e2e-app/`; specs assert per-pane WebSocket frame isolation, manual-connect laziness, workspace split/close/zoom/drag-resize/focus-navigation via real `Ctrl+B` chords, and that a live pane's socket survives sibling splits unblinked. GitHub Actions workflows run unit (PHP 8.3/8.4 × Laravel 12/13), integration, and e2e jobs.

### Fixed

- **Workspace divider drag was broken.** The drag geometry used Alpine's `$el` magic inside the divider's `pointermove` handler, where `$el` is the 8px divider element rather than the workspace container — so the pointer-to-ratio math divided by 8px instead of the workspace width and the split ratio oscillated between its min/max clamps instead of tracking the cursor. The component now captures the workspace root once at init and uses it for all geometry. Divider dragging is now smooth and tracks the pointer.
- **Live resize of SSH terminals was a silent no-op.** phpseclib's `setWindowSize()` only stores dimensions for the `pty-req` sent when the shell channel opens — calling it on an open shell never reaches the remote PTY. `WebSocket\InteractiveSsh` (an `SSH2` subclass) now sends the RFC 4254 §6.7 `window-change` channel request, so browser resizes propagate to remote shells. Proven by an integration test against a real sshd container.
- `TerminalBuilder` silently dropped SSH credentials when given a `ConnectionConfig` value object (the old `withConfig()` went through the credential-stripping `toArray()`), so SSH terminals built that way could never authenticate. `->connection($config)` now routes through `toTransportArray()`.
- `WebTerminalStream::ssh()` named its first parameter `$config`, so the documented named-parameter form (`->ssh(host: '…', username: '…')`) failed with "Unknown named parameter". The parameter is now `$host`; positional array/Closure usage is unchanged.

### Changed

- **Breaking — pre-1.0 fluent API clean break.** One connection vocabulary for both the schema component and `TerminalBuilder` (shared `ConfiguresConnection` trait): `ssh()` with named args is canonical (`privateKey:` replaces `key:`; `port` defaults to null → 22), `local(?workingDirectory, environment)` gains parameters, `workingDirectory()` exists on both surfaces; `sshWithPassword()`/`sshWithKey()`/`withConfig()`/`connection(type, array)` were removed. `streamTheme()` → `theme()`. `ConnectionBehavior::AutoWithButton`/`AutoHidden` → `Auto` (`'auto'`)/`Always` (`'always'`); `getEffectiveConnectionBehavior()` → non-null `getConnectionBehavior()`; `toFlags()` removed. Deprecated `windowControls()`/`startConnected()`/`autoConnect()` aliases, the `EmitsDeprecationNotices` machinery, and the `deprecations` config block were deleted. `StreamTerminal` lost the redundant `showWindowControls`/`autoConnect` props (derived from `chrome`/`connectionBehavior`) and its `streamTheme` prop is now `theme`. `log()` is named-args only. Default height unified at `400px` (fluent builders previously said `350px`). `TerminalGrid::terminals()` → `panes()`, `gap(int)` → `paneGap(int)` (Filament's boolean `gap()` is no longer overridden). Plugin `only()` removed; `withoutTerminalPage()`/`withoutTerminalLogs()` now subtract from the `components()` whitelist instead of being ignored. See UPGRADING.md §4b for the full old → new table.

- `filament/filament` (`^5.0`) added to `require-dev` (dev-only — the production `suggest` is unchanged) so the Filament-dependent tests (schema components, plugin) run for real instead of self-skipping. The previously skipped plugin tests were rewritten against the actual plugin API; the skipping had hidden stale assertions of Classic-era methods (`isEnabled()`, `disabled()`, `allowedCommands()`) that never existed in this package. `composer.lock` is now committed.
- The WebSocket server's ReactPHP stack (`react/socket`, `react/event-loop`, `ratchet/rfc6455`) moved from `require-dev`/`suggest` to `require` — it is the package's core and now installs automatically.
- **Breaking (vs. `mwguerra/web-terminal`):** Classic command-by-command mode was removed entirely — Stream is the only rendering path. The command whitelist/sanitizer/rate-limit security layer, interactive TUI sessions, mode toggles (`mode()`, `dual()`, `streamTerminal()`, `classicTerminal()`), and the related fluent knobs and config keys do not exist in this package.
- Package renamed to `mwguerra/web-terminal-stream` with namespace `MWGuerra\WebTerminalStream\`, config file `config/web-terminal-stream.php`, view/translation namespace `web-terminal-stream::`, `terminal-stream:*` Artisan commands, `terminal-stream/ws-token` route, and `terminal_stream_logs` table, so it can be installed side-by-side with `mwguerra/web-terminal`.
